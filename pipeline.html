📥 Data Acquisition

Downloaded 74M+ Records from Kaggle

Used the Kaggle API to download Grupo Bimbo's complete historical delivery dataset — 74 million weekly records across all of Mexico. The dataset spans products, shops, routes, and depots across the entire country.

# Download via Kaggle CLI kaggle competitions download -c grupo-bimbo-inventory-demand unzip grupo-bimbo-inventory-demand.zip

🧹 Memory Optimisation

Loaded 300K Rows With Memory-Efficient Dtypes

Used uint8/uint16/float32 instead of the default int64/float64 to cut RAM usage by 60% — absolutely essential for running this pipeline in Google Colab's free tier without crashing the runtime.

dtype_map = { 'Semana': np.uint8, 'Agencia_ID': np.uint16, 'Canal_ID': np.uint8, 'Venta_uni_hoy': np.float32, 'Demanda_uni_equil': np.float32, } df = pd.read_csv('train.csv', dtype=dtype_map, nrows=300_000) # 60% RAM reduction vs default dtypes
3
📐 Feature Engineering

Log-Transformed the Target Variable

Applied log1p() to the demand column. Demand is heavily right-skewed — most shops need 1–5 units, but some high-volume clients need 500+. Log transform makes the distribution learnable by the tree-based model and aligns with the RMSLE evaluation metric.

# Demand is heavily right-skewed — log makes it learnable df['log_demand'] = np.log1p(df['Demanda_uni_equil']) # Features: all columns except target features = ['Semana', 'Agencia_ID', 'Canal_ID', 'Ruta_SAK', 'Cliente_ID', 'Producto_ID', 'Venta_uni_hoy', 'Venta_hoy', 'Dev_uni_proxima', 'Dev_proxima']
4
🌲 Model Training

Trained a Random Forest (30 Trees, Max Depth 10)

An ensemble of 30 decision trees, each trained on a random subset of the data. Each tree votes independently, and the average vote is the final prediction. n_jobs=-1 used all available CPU cores to parallelise training for maximum speed. Try a live prediction →

from sklearn.ensemble import RandomForestRegressor model = RandomForestRegressor( n_estimators=30, # 30 trees in the ensemble max_depth=10, # max 10 levels deep n_jobs=-1, # use all CPU cores random_state=42 ) model.fit(X_train, y_train) # y_train = log1p(demand)
5
📊 Evaluation

Evaluated on 60,000 Held-Out Records

Used RMSLE (Root Mean Squared Log Error) — the official Kaggle scoring metric — to measure prediction quality on 60,000 records the model had never seen. This ensures the score reflects real-world generalisation, not just training data performance.

from sklearn.metrics import mean_squared_log_error import numpy as np y_pred_log = model.predict(X_val) y_pred = np.expm1(y_pred_log).clip(min=0) y_true = np.expm1(y_val) rmsle = np.sqrt(mean_squared_log_error(y_true, y_pred)) print(f"Validation RMSLE: {rmsle:.4f}")
6
🚀 Production Inference

Generated 6,999,251 Predictions on test.csv

Applied the trained model to all test records, reversed the log transform using expm1(), clipped negative values to zero, and saved submission.csv — ready to upload to Kaggle for scoring.

# Load full test set and generate predictions test = pd.read_csv('test.csv', dtype=dtype_map) test_preds_log = model.predict(test[features]) test_preds = np.expm1(test_preds_log).clip(min=0) # Save Kaggle submission submission = pd.DataFrame({ 'id': test['id'], 'Demanda_uni_equil': test_preds }) submission.to_csv('submission.csv', index=False) # 6,999,251 predictions saved ✓
