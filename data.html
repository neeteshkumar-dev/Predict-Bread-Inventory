🗂️ Data Dictionary

What Each Data Field Means

The model uses 10 input fields from Grupo Bimbo's weekly delivery records to predict inventory demand. Here's what each one means — in plain English. See how these fields power the ML pipeline →

🔑 Identifier Fields

Location & Context Variables

These categorical fields tell the model who, where, and when — providing context for the prediction.

📅
Week Number
Semana · Integer · Range: 1–9
Which week of the sales period. Helps the model detect seasonal patterns — some weeks sell significantly more than others, especially around holidays.
🏬
Sales Depot ID
Agencia_ID · Categorical Integer
Each depot is a regional warehouse that distributes to a geographic area. Different depots serve different parts of Mexico, each with its own demand patterns and product mixes.
🛒
Sales Channel
Canal_ID · Categorical Integer
The type of shop — supermarket chain, small neighbourhood kiosk, restaurant, or wholesale buyer. Each channel has dramatically different volume and return behaviour.
🗺️
Delivery Route
Ruta_SAK · Categorical Integer
The specific truck route that services this shop. Each route visits the same set of shops every week. Route context helps the model understand geographic demand clustering.
🏪
Shop / Client ID
Cliente_ID · Categorical Integer
Unique identifier for every individual shop or client that receives deliveries. There are millions of unique clients across Mexico — each has its own historical demand pattern.
🍞
Product ID
Producto_ID · Categorical Integer
Which specific bread, cake, tortilla, or snack product. Bimbo has hundreds of products — each with its own shelf life, price point, and demand curve.
📊 Predictive Signal Fields

This Week's Performance Data

These four numerical fields are the actual predictive signals. Units sold this week is the most powerful single predictor — accounting for 97% of the model's decision. See how the model uses them →

📦
Units Sold This Week
Venta_uni_hoy · Float32
How many units the shop actually sold this week. This is the single most powerful predictor — it directly signals how hungry the shop is for product. The model assigns 97% of its predictive weight to this field.
⭐ 97% Feature Importance
💰
Sales Revenue This Week
Venta_hoy · Float32 · Pesos (₱)
Total pesos earned from sales this week. Reflects both volume and the price of products sold. Correlated with units sold but adds price-point context — a shop selling premium products has different patterns.
⬦ 0.3% Feature Importance
↩️
Returns Next Week (Units)
Dev_uni_proxima · Float32
Units of unsold or stale bread returned to the delivery truck next week. High return count signals the shop was overstocked this week — the model should send less next time. The model weights this at 2%.
⬦ 2% Feature Importance
🔄
Returns Next Week (Pesos)
Dev_proxima · Float32 · Pesos (₱)
Monetary value of returned product. Helps the model understand the financial severity of overstocking — not just how many units came back, but what they were worth.
⬦ 0.8% Feature Importance
🎯 Target Variable

What the Model Predicts

🎯
Predicted Demand — Adjusted Units
Demanda_uni_equil · Float32 → Integer
The adjusted demand in units. This is what the model predicts and what it was trained on. It represents the true quantity the shop needed — calculated from the Bimbo dataset as: Adjusted Demand = Units Sold + Units Returned − Stale Adjustments. The delivery truck should bring exactly this many units next week to neither overstock nor understock the shop. Try the live predictor →
